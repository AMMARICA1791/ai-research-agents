# AI Research Agents — مختبر مستقل للبحث والتطوير

الهدف الحالي هو تطوير مركز بحثي خاص متعدد الوكلاء، وليس بيع الخدمات.

## ما يعمل فعلياً
- وكيل الاستكشاف: فحص ملفات المشروع المسموحة دون تنفيذها.
- وكيل التحليل: تحليل بنية Python بأدلة من الملفات والأسطر.
- وكيل الهندسة: اقتراح الإصلاحات دون تعديل الشيفرة.
- وكيل التحقق: مراجعة الأدلة والتحقق من المخرجات.
- وكيل التقارير: إعداد تقرير وحفظه في SQLite.

ينسق البرنامج العمل بين الأدوار الخمسة. أما الوكلاء القدامى في agents/
فهم أمثلة ذات نتائج ثابتة وليسوا باحثين أذكياء مستقلين.

يمكن ربط نموذج لغوي خارجي اختيارياً بعد إعداد الخدمة والمفتاح والموديل.
بدون ذلك تعمل أدوات التحليل المحلي الحقيقي، ويظهر أن النموذج غير مفعّل.

## التشغيل على GitHub بواسطة التابلت
افتح Actions، واختر Research Lab - Manual Mission ثم Run workflow.
اكتب هدفاً بحثياً، وبعد التنفيذ نزّل التقرير وقاعدة SQLite من Artifacts.
الذاكرة تخص تشغيل GitHub الواحد؛ قاعدة سحابية دائمة بين التشغيلات
غير موجودة بعد.

## التشغيل المحلي
    pip install -r requirements.txt
    python main.py

الواجهة: http://127.0.0.1:8000

    python -m lab.cli mission --repo . --goal "Audit the research laboratory"
    python -m lab.cli history
    python -m lab.cli proposals

كل مقترح يتطلب مراجعة بشرية. حتى الموافقة لا تعدل الملفات تلقائياً.
لا تنشر الواجهة للعامة قبل توثيق المستخدمين والحماية المناسبة.

الملفات التجارية القديمة مؤرشفة في archive/commercial-drafts/
