# AI Research Agents — مختبر بحثي مفتوح بالأدلة

> **سبع مراحل تنسيق وتنفيذ، وليست سبعة نماذج ذكاء اصطناعي مستقلة.** المركز ما زال تجريبياً ويشترط مراجعة بشرية للنتائج.

هدفنا بناء أدوات برمجية مجانية قدر الإمكان لفحص الشيفرة واختبار مقترحات الذكاء الاصطناعي وعرض الأدلة على نجاحها أو فشلها.

**الحالة:** مشروع تجريبي، وليس منصة تجارية أو نظاماً مستقلاً لإصلاح جميع البرامج. لدينا سبع مراحل منظمة وليست سبعة عقول ذكاء اصطناعي مستقلة.

## ثلاث أوامر لتجربة النتائج الموثقة

يمكن للباحث إعادة التجارب المدمجة دون مفاتيح مدفوعة باستخدام Python 3.11 أو أحدث: [DEMO.md](DEMO.md). لا تعيد هذه التجربة تشغيل Qwen أو إنتاج إصلاح جديد.

## شاهد التجربة المنشورة على GitHub

افتح [العرض التجريبي الموثق على GitHub](https://github.com/AMMARICA1791/ai-research-agents/actions/workflows/public-demo.yml)، واختر **آخر تشغيل ناجح** لقراءة صفحة **Summary**؛ مشاهدة النتائج متاحة للزوار. زر **Run workflow** مخصص لمن لديهم صلاحية الكتابة في المستودع، أما المطور الخارجي فيستطيع نسخ المشروع وتشغيل التجربة على نسخته. يحتاج تنزيل ملف النتائج من واجهة GitHub إلى تسجيل الدخول. لا يلزم اشتراك ذكاء اصطناعي مدفوع أو كمبيوتر لمشاهدة التقرير.

يعيد العرض اختبار 8 أمثلة اصطناعية، وإصلاح اصطناعي قبل/بعد، والمشكلة البرمجية الحقيقية التي أصلحها Qwen سابقاً في [PR #17](https://github.com/AMMARICA1791/ai-research-agents/pull/17). **العرض لا يشغّل Qwen مجدداً ولا يكتشف عيوباً جديدة من تلقاء نفسه.** راجع [دليل التجربة](docs/PUBLIC_DEMO.md).

## ماذا أنجزنا؟
- فحص شيفرة Python لبعض أنواع المشكلات.
- حفظ ملخصات منقّحة بين تشغيلات GitHub.
- تشغيل Qwen عبر Ollama دون مفاتيح مدفوعة.
- نموذج Qwen كتب إصلاحاً لشيفرة حقيقية في محلل روابط GitHub، نجحت اختباراته ثم وافق صاحب المشروع على دمجه في [PR #17](https://github.com/AMMARICA1791/ai-research-agents/pull/17).
- تجارب اصطناعية قابلة لإعادة الاختبار؛ لا تثبت نجاحاً عاماً على كل المشاريع.

## بداية البحث والاستكشاف العلمي خارج فحص البرامج

أضفنا [مستكشف المصادر البحثية العامة](.github/workflows/scholarly-discovery.yml)، وهو يسترجع **بيانات وصفية حقيقية للأبحاث** من فهرس Crossref العام حول موضوع بحثي معلن، ويسجل معرّفات DOI وتاريخ الاسترجاع ومصدر البيانات وحدود النتائج. **لا يقرأ الأوراق العلمية كاملة، ولا يثبت صحة نتائجها، ولا يشغّل نموذج ذكاء اصطناعي**. هذه أول خطوة اختبارية في البحث والاستكشاف، وليست وكيلاً بحثياً مستقلاً. [المنهج والحدود](docs/SCHOLARLY_DISCOVERY.md).

[أداة الفحص على GitHub](.github/workflows/public-repo-audit.yml) | [حدود الفحص وضماناته](docs/PUBLIC_REPO_AUDIT.md). يستطيع الزائر مشاهدة النتائج المنشورة؛ تشغيل المهمة داخل مستودعنا يحتاج إلى صلاحية كتابة.

هذا فحص ثابت محدود، **وليس تدقيقاً أمنياً معتمداً أو إصلاحاً آلياً عاماً**.

## الحالة الحالية الموحّدة — أكتوبر 2026

- المشروع مختبر أبحاث تجريبي، وليس خدمة SaaS جاهزة أو مطوّراً مستقلاً. المراحل السبع خطوات تنسيق وليست سبعة وكلاء تفكير مستقلين.
- [التجربة بثلاثة أوامر](DEMO.md) تعمل ببايثون 3.11+ دون مفتاح API أو نموذج محلي، وتعرض 8 حالات اصطناعية وإصلاحاً اصطناعياً حتمياً وإعادة اختبار الحالة التاريخية في [PR #17](https://github.com/AMMARICA1791/ai-research-agents/pull/17). **لا تعيد تشغيل Qwen**.
- [تدقيق مستودعات Python العامة](docs/PUBLIC_REPO_AUDIT.md) قراءة وتحليل ثابت محدود دون تنفيذ الشيفرة الخارجية، والنتائج إشارات للمراجعة البشرية لا شهادات أمنية.
- [اكتشاف المراجع العلمية](docs/SCHOLARLY_DISCOVERY.md) يجلب بيانات Crossref الوصفية مع المصدر ووقت الجلب وعدم اليقين؛ لا يقرأ الأبحاث كاملة ولا يقيّم جودتها ولا يستخدم نموذجاً لغوياً.
- [توثيق الإصدار](VERIFIED_RELEASE.md) يفصل الأدلة التاريخية عن الاختبارات الجديدة؛ [المساهمة](CONTRIBUTING.md) محدودة النطاق حالياً. لا يوجد ضمان إنتاجي.
