# AI Research Agents — مختبر بحثي مفتوح بالأدلة

هدفنا بناء أدوات برمجية مجانية قدر الإمكان لفحص الشيفرة واختبار مقترحات الذكاء الاصطناعي وعرض الأدلة على نجاحها أو فشلها.

**الحالة:** مشروع تجريبي، وليس منصة تجارية أو نظاماً مستقلاً لإصلاح جميع البرامج. لدينا سبع مراحل منظمة وليست سبعة عقول ذكاء اصطناعي مستقلة.

## ماذا أنجزنا؟
- فحص شيفرة Python لبعض أنواع المشكلات.
- حفظ ملخصات منقّحة بين تشغيلات GitHub.
- تشغيل Qwen عبر Ollama دون مفاتيح مدفوعة.
- نموذج Qwen كتب إصلاحاً لشيفرة حقيقية في محلل روابط GitHub، نجحت اختباراته ثم وافق صاحب المشروع على دمجه في [PR #17](https://github.com/AMMARICA1791/ai-research-agents/pull/17).
- تجارب اصطناعية قابلة لإعادة الاختبار؛ لا تثبت نجاحاً عاماً على كل المشاريع.

## كيف أجرّبه؟
من GitHub افتح Actions ثم Research Lab - Persistent Missions ثم Run workflow، ولا تضع معلومات سرية في الهدف. لتجربة نموذج مجاني اختر Zero-Key Local Qwen Research. راجع [البدء السريع](QUICKSTART.md).
