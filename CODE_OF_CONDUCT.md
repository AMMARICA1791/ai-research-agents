# Community code of conduct

We want a respectful, accessible and technically rigorous community for beginners and experienced developers.

Please:
- Discuss implementations and evidence, not people's identities.
- Respect beginners and respond constructively to good-faith questions.
- State experimental limitations and acknowledge mistakes openly.
- Respect privacy, copyrights, licenses, and platform rules.
- Avoid harassment, discrimination, threats, spam, and disclosing private information.

Maintainers may moderate or close disruptive issues and restrict repeated abuse. This project is maintained on a best-effort basis; no response time is guaranteed.

Report abuse through GitHub's platform reporting tools. Do not post private personal details publicly. See [SECURITY.md](SECURITY.md) for sensitive technical disclosures. The repository does not yet publish a dedicated private community email.
