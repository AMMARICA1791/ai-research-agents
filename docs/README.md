## Reproduce the bounded three-command demo

From the repository root with Python 3.11+:

```sh
python -m lab.public_demo --repo . --out results/public-demo
python -m lab.benchmark
python -m lab.autorepair
```

These commands do not run local Qwen inference, discover unknown bugs or independently verify scientific publications. See [DEMO.md](../DEMO.md) for what each test proves.

To inspect additional experiments, check the matching workflow and the provenance-backed report before drawing conclusions. Third-party source material retains its own licensing terms.
