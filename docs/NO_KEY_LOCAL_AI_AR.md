# تشغيل نموذج ذكاء اصطناعي مجاني دون مفاتيح داخل المختبر

يحتوي مشروع AI Research Agents الآن على مسار اختياري للتشغيل باستخدام
Ollama وQwen2.5:0.5b، وهو نموذج مفتوح الأوزان بحجم يقارب 398 ميغابايت.
لا يحتاج إلى API KEY ولا حساب مدفوع لدى مزود ذكاء اصطناعي.

## التجربة داخل GitHub Actions

من صفحة المستودع اختر Actions ثم Zero-Key Local Qwen Research ثم
Run workflow. سير العمل هذا يجلب Ollama والنموذج إلى خادم GitHub القياسي،
ويجري تحليل الشيفرة المحلي ثم يستدعي النموذج فعلياً مرتين لمراجعة
الملاحظات، ويحفظ تقريراً في Artifacts.

عند النجاح ستظهر في السجل:
LIVE_FREE_LOCAL_INFERENCE_CONFIRMED
MODEL=qwen2.5:0.5b
REAL_MODEL_REVIEWS=2

التشغيل يعمل محلياً داخل خادم CI المؤقت: لا يوجد اشتراك في خدمات AI
ولا تُرسل البيانات إلى واجهة توليد مدفوعة. تنزيل برنامج Ollama
وأوزان النموذج من الشبكة مطلوب في كل تشغيل إن لم يكن مخزناً.

## القيود

- النموذج صغير (0.5B)، وبالتالي جودة الاستنتاج والبرمجة محدودة؛
  لا يرقى إلى مستوى النماذج الكبيرة.
- يجب التحقق من صحة مخرجاته بالأدلة، ولا يسمح له بإجراء تعديل تلقائي.
- GitHub Actions القياسي مجاني للمستودعات العامة بحسب قواعد GitHub،
  لكنه ليس خادماً يعمل باستمرار؛ مهمة واحدة مؤقتة، كما توجد قيود استخدام.
- لا تنتقل إليه الشيفرة أو ملفات الأسرار أو أهداف المهمات التفصيلية؛
  يرسل المحرك إليه فئات إحصائية قصيرة على loopback (127.0.0.1).
- لا يستخدم هذا المسار مفاتيح Secrets أو إعدادات LAB_LLM_API_KEY
  المطلوبة في المسار الاختياري المدفوع.
- المهمة المجانية لا تحدث فرع lab-memory تلقائياً؛ مسار الذاكرة
  الدائمة منفصل، ويستطيع حفظ إحصاءات التشغيل وفق تصميمه الخاص.

## التشغيل على خادم شخصي إن توفر مستقبلاً

1. ثبت Ollama على جهاز يدعم النموذج.
2. شغل ollama pull qwen2.5:0.5b
3. اجعل Ollama يعمل على 127.0.0.1:11434.
4. ضع LAB_MODEL_BACKEND=ollama، ثم شغل:
   python -m lab.cli mission --repo . --goal "Review the laboratory code"

إذا لم تتوفر خدمة Ollama فسيظهر local_model_unavailable بدلاً من
الادعاء أن النموذج قام بالبحث.
