# Independent Research & Development Laboratory

Primary purpose: an internal research center, not a commercial service.

Phase 1 runs five evidence-based roles: Explorer, Analyst, Engineer, Validator, and Synthesizer. The roles gather permitted source metadata, produce AST findings, create human-review proposals, check evidence, and save reports. SQLite holds mission history and decisions on the host where a task executes. GitHub Actions produces a run-specific artifact, not a database shared between runs.

Optional external model reasoning requires an explicitly configured endpoint, API key, and model name. Without those, deterministic research runs and reports model_mode=not_configured. Existing older agents are examples with static outputs rather than verified independent researchers.

No automated commits or merges, no unattended execution, and no action on a proposal without separate human approval. Future work: deeper analysis, additional tools, model evaluations, persistent shared cloud memory and gated code proposals.
