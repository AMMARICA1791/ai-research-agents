# Software license: explicit owner decision pending

**No open-source license has yet been approved.** Public GitHub visibility alone does not grant permission to copy, modify or redistribute software.

The old root file named `LICENSE` contained a Python server launcher, not a license. This foundation change removes the incorrectly named file without granting rights or deciding the license for the owner.

Two common permissive choices:
- **MIT**: brief and permissive, allows commercial and closed-source reuse subject to notice requirements.
- **Apache-2.0**: permissive with more explicit patent and notice terms; also permits commercial reuse subject to terms.

Neither license guarantees exclusive ownership of ideas or commercial success. Existing third-party code must be reviewed for compatible redistribution rights.

**Next owner decision:** explicitly approve MIT, Apache-2.0, or another suitable license. Only then create the official `LICENSE` file and update contributor policy in a reviewed pull request. Until approval, collect bug reports, benchmark ideas and feedback rather than merging third-party source contributions.
