# Example: Handling an unverified research claim

**User prompt:** "A new AI model reduces hallucinations by 80%. Is this scientifically proven?"

**Expected skill behavior (illustrative, not a measured agent output):**

- **Scope:** Identify which model, baseline, metric, evaluation dataset, date, and definition of hallucination are intended.
- **Evidence inventory:** No sources supplied; no live retrieval performed. **Access status: unavailable.**
- **Claim matrix:** "80% reduction" → **unverified**; no primary study, dataset, confidence interval, or independent replication provided.
- **Alternative explanations:** Changed evaluation set, denominator, prompting, cherry-picked cases, or different hallucination definitions.
- **Reproducibility plan:** Compare baseline and candidate under identical prompts and datasets; preregister evaluation and annotate errors blindly.
- **Conclusion:** Insufficient evidence to confirm or reject the numerical claim.
- **Human review:** Obtain the original study, inspect methods and statistics, and reproduce the comparison.

This is a teaching example. It is **not** an actual test result or proof of skill performance.
