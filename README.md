# 🤖 AI Research Agents Platform

**المنصة العربية الأولى لبحث أدوات الذكاء الاصطناعي بنظام متعدد الوكلاء**

> نظام بحثي متقدم يستخدم عدة وكلاء ذكية متخصصة للعمل معاً في دراسة وتحليل وتقييم أدوات الذكاء الاصطناعي الحديثة

---

## 🎯 الرؤية

بناء منصة بحثية مفتوحة المصدر حيث تعمل وكلاء ذكية متخصصة بشكل تعاوني لـ:
- 🔍 اكتشاف وتحليل أدوات الذكاء الاصطناعي الناشئة
- 📊 إجراء دراسات معايرة صارمة (Benchmarking)
- 📝 توليد أوراق بحثية وتقارير
- 🔄 مشاركة التجارب القابلة للتكرار
- 💡 بناء قاعدة معرفة جماعية

## 📋 الوكلاء المتخصصون

### 🔍 **وكيل الاستكشاف (Explorer)**
- يبحث عن أدوات جديدة في الإنترنت والمستودعات
- ينظم الأدوات ويصنفها
- يحدد فرص البحث الجديدة

### 📖 **وكيل التحليل (Analyst)**
- يفحص تفاصيل الأدوات بعمق
- يقارن بين الطرق المختلفة
- يستخرج الدروس المهمة

### ⚡ **وكيل الاختبار (Benchmarker)**
- يصمم اختبارات الأداء
- يقيس سرعة ودقة الأدوات
- يقارن النتائج برسوم بيانية

### 📄 **وكيل التوليف (Synthesizer)**
- يجمع نتائج الوكلاء الآخرين
- يكتب تقارير منظمة وسهلة الفهم
- ينشئ أوراق بحثية احترافية

### ✅ **وكيل التحقق (Validator)**
- يتأكد من صحة النتائج
- يتحقق من إمكانية تكرار التجارب
- يضمن جودة البيانات

## 🚀 البدء السريع

### 1️⃣ **التثبيت (بسيط جداً)**

```bash
# انسخ المستودع
git clone https://github.com/AMMARICA1791/ai-research-agents.git
cd ai-research-agents

# أنشئ بيئة معزولة
python -m venv venv
source venv/bin/activate  # على Windows: venv\Scripts\activate

# ثبّت المكتبات
pip install -r requirements.txt

# شغّل البرنامج
python main.py
```

### 2️⃣ **تشغيل مشروع بحثي**

```bash
# ابدأ دراسة جديدة
python research/init_project.py "دراسة مقارنة نماذج اللغة"

# شغّل خط أنابيب الوكلاء تلقائياً
python research/run_pipeline.py
```

### 3️⃣ **انتظر النتائج**

سيقوم النظام تلقائياً بـ:
1. 🔍 اكتشاف الأدوات ذات الصلة
2. 📖 تحليل خصائصها
3. ⚡ اختبار الأداء
4. 📄 كتابة تقرير شامل
5. ✅ التحقق من الصحة
