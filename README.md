# AI Research Agents Platform

A multi-agent AI research platform for discovering, analyzing, benchmarking, and reporting on AI tools and algorithms.

## Overview

This project is designed for collaborative AI research workflows where specialized agents work together on a single research mission.

## Structure

- `agents/` — specialized research agents
- `research/` — project and findings management
- `experiments/` — benchmark and experiment tracking
- `docs/` — documentation

## Quick start

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Agents

- Explorer: finds and catalogs AI tools
- Analyst: performs deep technical analysis
- Benchmarker: evaluates model performance
- Synthesizer: generates narrative reports
- Validator: checks quality and reproducibility
